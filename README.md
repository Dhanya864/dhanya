## 📤 Step-by-Step GitHub Upload & Hosting Guide

Follow these commands to upload this project to your GitHub account and publish it live:

### Step 1: Initialize Git & Commit Files
Open Terminal / PowerShell in the project directory (`C:\Users\dhanyasri\.gemini\antigravity\scratch\jewellery-store`):

```bash
# 1. Initialize Git repository
git init

# 2. Add all files to staging
git add .

# 3. Create initial commit
git commit -m "Initial commit - AURA Jewellery E-Commerce Website"
```

### Step 2: Create a New GitHub Repository & Push Code
1. Go to [GitHub New Repository](https://github.com/new).
2. Name your repository: `aura-jewellery-store`.
3. Set visibility to **Public**.
4. Click **Create repository**.
5. Copy the commands shown under "push an existing repository from the command line" and run them:

```bash
# Rename branch to main
git branch -M main

# Link local repository to your remote GitHub repo
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/aura-jewellery-store.git

# Push code to GitHub
git push -u origin main
```

---

### Step 3: Publish & Host Live (Free GitHub Pages)

1. Go to your repository on GitHub (`https://github.com/YOUR_GITHUB_USERNAME/aura-jewellery-store`).
2. Click on **Settings** > **Pages** (under Code and automation in the left sidebar).
3. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
4. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
5. Wait 1-2 minutes! GitHub will generate your live URL:
   `https://YOUR_GITHUB_USERNAME.github.io/aura-jewellery-store/`
